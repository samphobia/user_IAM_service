# Credit_PD

Workspace folder for the upcoming Credit PD service.

## Service Location

- `credit-pd-service/`

## Layered Structure

The service scaffold mirrors the layered package layout used in the IAM workspace:

- `controllers`
- `service`
- `auth`
- `config`
- `security`
- `dto`
- `entities` and `entities/enums`
- `repository`
- `exception`
